# Train Reservation System

## Project Description
The Train Reservation System is a web-based application developed to simplify the process of searching trains and booking train tickets. It allows users to view available trains, select travel details, enter passenger information, and book tickets.

## Features
- View available trains.
- Search trains based on source and destination.
- Select journey date and travel class.
- Enter passenger details.
- Book tickets for multiple passengers.
- Generate a PNR number.
- Display booking confirmation and ticket details.

## Technologies Used
- **Frontend:** HTML, CSS, JSP
- **Backend:** Java, Servlets
- **Database:** Apache Derby
- **IDE:** NetBeans
- **Server:** GlassFish

## Project Structure
- `src` – Java source files and backend logic.
- `web` – JSP pages, HTML, CSS, and web resources.
- `nbproject` – NetBeans project configuration.
- `build.xml` – Project build configuration.

## How to Run
1. Download or clone this repository.
2. Open NetBeans IDE.
3. Open the project folder.
4. Configure the required database connection.
5. Configure the GlassFish server.
6. Build and deploy the project.
7. Open the application in your browser.

## Project Purpose
This project was developed for academic learning to understand Java web development, database connectivity, and online ticket reservation workflows.
